# TerraNova 参考站与壤脉天玑融合建议

日期：2026-11-01｜结论：可以融合，采用视觉语言与交互节奏，保留现有 Vue/FastAPI 业务结构。

## 参考依据

用户提供的 `terra-nova-precision-agri-tech-hero-and-single-page-experience.zip` 内含 Next/React 单页、Tailwind、Framer Motion、农田主图及一套通用 UI 组件。本次检查了 `app/page.tsx`、`app/globals.css`、`package.json` 和 `public/hero-field.jpg`。压缩包没有可见的图片授权文件或真实运营指标来源；其文字和数字仅作为演示素材。

## 可借用的设计元素

| 参考站元素 | 壤脉天玑落点 |
| --- | --- |
| 大幅农田影像、深色渐层和大标题 | 首页首屏，用一句中文说明“从土壤数据到可追溯的健康评价”；主按钮进入空间探索，次按钮进入上传评价 |
| 悬浮白色圆角导航、绿色行动按钮 | 统一主导航，但工作台内改为紧凑的固定顶栏，避免遮挡地图与表格 |
| 半透明信息卡 | 首页四模块入口和数据来源摘要；数据表格与评价结果使用实体浅色底，保障数值可读 |
| 简短动效和页面切换 | 首页入场和按钮反馈；地图、筛选、上传任务保持即时反馈，并尊重减少动态效果设置 |
| 清晰的标题层级与宽留白 | 知识文章、数据集详情、报告封面；高密度工作台保留适当信息密度 |

## 不直接移植的内容

- 参考站的 `10K+` 客户、`32%` 增产、`18` 个国家、节水 `40%`、生物工程种子等文案没有本项目证据，不作为网站事实。
- `href="#"` 的导航和按钮只是展示占位，应连接壤脉天玑真实路由与任务。
- 现有 Vue/Vite + FastAPI、Leaflet 地图和 SQLite 接口继续作为基础。将整个站改写为 Next/React 会增加迁移成本，不能带来对应的数据或算法能力。
- 参考主图是拖拉机喷洒场景，容易让“土壤健康评价”被理解为农药作业服务；可先做视觉占位，正式发布前换成有使用权且更贴近土壤剖面、采样或地块数据的影像。
- 图片来源/使用许可未在包内核实，正式公开前需确认。

## 建议页面结构

1. **品牌首页**：影像首屏、两项明确行动、四模块入口、数据与方法状态、最近更新。营销文字不放未经核验的科研或商业数字。
2. **空间探索**：保留左侧图层、中央地图、右侧剖面；统一导航和色彩，地图图例与状态优先于装饰。可在入口使用影像横幅，工作台主体不铺满背景图。
3. **数据资源中心**：白底目录与筛选面板，突出来源、年份、许可、可下载状态。沿用参考站圆角与排版节奏，但减少毛玻璃效果。
4. **AI 健康评价**：独立五步任务页，影像只用于介绍与报告封面；表单、原始值、质量门槛和计算结果保持稳定对比度。
5. **知识与工具**：更接近参考站的图文卡片风格，文章正文保留来源、适用条件和未核查部分。

## 实施顺序与验收

先做首页与全站导航的视觉样板，确认品牌影像、主色、中文标题和移动端首屏；随后抽取共享设计令牌与按钮/卡片；最后逐模块改造，不同时重写业务接口。每次改版需检查地图可操作区域、表格可读性、表单错误状态、键盘焦点与移动端布局。

大图作为首页首屏资源时，准备响应式尺寸和现代压缩格式，预留画面比例避免布局跳动；非首屏图片延后加载。动效应轻量，减少动态效果偏好下停止非必要过场。这些要求与 `modern-web-guidance` 的响应式和性能建议一致。
