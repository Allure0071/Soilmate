# 前端第一轮审核：布局、导航与动态录入

本轮仅实现用户确认的第 1、2、3 项，不实现接口传输、模型评价、结果生成、文件解析或真实地块保存。原接口草案仍待后端确认，本次没有改动后端代码或契约定义。

## 预览

- 本地开发审核入口：`http://127.0.0.1:5173/assessment/preview`。
- 快速模式：`/assessment/preview?mode=quick`；深度模式：`/assessment/preview?mode=deep`。
- `/assessment/preview` 仅在 Vite 开发模式允许匿名审核，显示明确的审核标记，且不读取受保护的个人健康数据。
- 正常 `/assessment` 继续要求账号登录；账号页合法返回目标已增加 `/assessment`。
- 生产构建中匿名审核开关关闭；实际部署的 SPA 路由由后端同学按后续联调约定提供。

## 已实现

1. 健康评价按步骤分页：选择方式 → 检测录入 → 录入确认；深度分析在录入前增加独立的地块资料页。移除录入页的右侧摘要与追问占位区。
2. 首页健康评价按钮、新主站导航、返回地图、返回首页、浏览器历史恢复。
3. 动态增删指标、切换单位、单指标检查、非法数值/重复项提示、补充采样信息。
4. 本机草稿自动保存与恢复，区分匿名审核和不同账号；不声称已经保存到服务器。
5. 明确标注的示例填入操作，不覆盖已有数值；既有输入在模式切换后保留。

指标列表是前端审核用元数据，正式代码、单位、检测方法及模型特征映射仍由后端确认。前端不做指标归一化、评分、物理量换算或科学诊断。

## 建议审核顺序

1. 选择快速试用，点击“开始录入”，输入一项 pH 值，点击“下一步：确认录入”。确认页应只显示录入内容，不生成评价。
2. 添加第二项，切换成 TN 并选择报告单位；尝试非法数字，确认错误定位。
3. 删除指标，检查至少一项可通过、全部留空时有提示。
4. 通过“更换评价方式”返回选择页，切到深度分析，经过独立地块资料页填写名称、作物与背景，检查原指标保留。
5. 刷新页面，检查本机草稿恢复；返回地图，再用浏览器后退恢复预览。
6. 在窄屏中检查导航、表单、删除按钮和滚动。

各页通过 `step=mode|background|input|review` 区分，支持浏览器前进、后退、刷新和返回修改。直接访问确认页时会重新检查本机草稿；无有效输入则退回录入页。快速模式跳过地块资料页。选中模式与主操作使用深绿色，提高区分度。

后续评价与追问将独立呈现，当前确认页仅提示分析服务待接入。文件导入及 N+X 时间线也待接入，不会生成伪造结果或暗中调用模型。

## 视觉优化

保留分步流程和全站田野绿风格，收紧页头占高，统一页头与表单的对齐；地块名称与作物并列，位置与选填背景依次展示。已完成步骤支持直接返回，保留草稿。图标使用一致的 SVG 描边；输入边界、焦点和按钮状态更明确。确认页优先显示检测值，再显示地块与样本资料。文件导入呈禁用状态并说明待接入。
