# 答辩演示模式说明（/demo）

版本：2026-11-04。状态：**演示用案例流程，不是已验收的正式评价功能**。

## 1. 它是什么

`/demo` 是独立的答辩演示页：用一组**有公开来源的土壤属性数据**，完整走一遍"案例地块 → 数据接入与核验 → N+X 选测 → 稳健评分 → 证据化解释 → 多 Agent 复核 → 报告 → 对照地块与可比性"的信息链路，用于答辩现场讲解产品结构与边界。

- 纯前端实现，不发起任何后端请求，不读写数据库，不依赖模型服务、GPU 或网络。
- 开发服务器（`npm run dev`）与生产构建（`npm run build` + FastAPI）都可用；首页页脚提供入口。
- 页面加载时用固定规则在浏览器内计算，结果可复现。

## 3. 计算规则（演示参数）

- 采用 SMAF 型连续评分曲线（适宜区间/越高越好/越低越好三类曲线）计算单指标得分，再按功能权重合成生产支持、养分供给、土壤结构、水分调节四项功能分。
- 三套演示规则集：A 文献最适区间、B 区域参照分位、C 保守阈值（短板优先），输出综合分区间与等级稳定性。
- N+X 选测使用"规则 A 下把某指标得分置 0 后综合分下降量"作为演示边际贡献，在 5 项预算内选择 N=3、X=2，其余记为预算外。
- **规则参数为演示值，未经独立验证**；不构成健康等级诊断或科研结论。正式评分规则需在实验验证后替换。

## 4. 现场演示步骤（约 7 分钟）

1. 打开 `/demo`，先讲第 1 步"案例与来源"：数据来自 SoilGrids 2.0 公开查询，是 250 m 区域预测值，不是本地实测。
2. 第 2 步展示 6 项属性、单位换算、数据版本与 1 项证据缺口；点"开始计算（案例）"播放 5 阶段进度。
3. 第 3 步讲 N+X：预算 5 项、N=3、X=2（容重、黏粒）、CEC 被挤出并记录取舍。
4. 第 4 步讲稳健评分：雷达图、区间 66–84、三套规则（84/78/66.8）等级覆盖较好/中等、稳定短板（SOC、CEC）与敏感项（容重）。
5. 第 5 步讲证据化解释：每条结论挂数据查询、规则版本与缺口；规则模板生成解释、不改数值。
6. 第 6 步讲多 Agent 复核：版本冲突 → 阻止发布 → 回退重算 → 报告 v2。
7. 第 7 步下载案例报告（HTML，可打印 PDF）；第 8 步讲对照地块 B-02：同源同深度可横向比较，但不是复测。

操作：上一步/下一步按钮、键盘 `←`/`→`、`Esc` 退出、右上角"自动播放"。

## 5. 真实能力对照

现场可独立演示的真实功能：探索数据地图与点位查询、数据资源库、工具中心（如质地三角图）、健康研究录入与核验、研究工作台的土样审计与报告版本。

尚未接入：`/api/assessment` 的评分接口、N+X 的真实训练结果、微调模型服务、多 Agent 的自动调度。演示模式不会掩盖这些缺口，答辩时应主动说明"数据为公开区域预测值、规则为演示参数、模型未接入"。
