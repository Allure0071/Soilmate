# Soilmate 统一视觉与动效

## 结构与导航

沿用上游共享的 `src/SiteHeader.vue`、`src/siteNavigation.js` 和 `src/site-shell.css`。页面切换保留同一套导航入口、当前状态、账号操作和外框尺寸；模块工具放在内容区。上游品牌名称与路由保持原样。

共享导航在原生内容滚动中粘附于外框顶部，防止跨页残留滚动位置把它带出视口；不修改组件的入口与结构。

## 字体

正文、标题、按钮、表单和数字统一使用 HarmonyOS Sans SC。`public/assets/design-system/typography.css` 是字号、行高和字族的入口；`--font-display` 与 `--font-ui` 指向相同字族。真正的代码和序列保留等宽字体。

字体来自[华为官方设计资源](https://developer.huawei.com/consumer/cn/design/resource-V1)的[原始字体包](https://developer.huawei.com/images/download/general/HarmonyOS-Sans.zip)。本项目使用未修改的 Regular、Medium 和 Bold TTF，不转换格式、不裁剪字形。字体文件及原始许可位于 `public/assets/fonts/harmonyos/`，页面页脚提供字体使用声明与许可链接。

## 圆角与玻璃表面

`public/assets/design-system/surfaces.css` 统一 Vue 与独立账号页的材质。工作区圆角 28 px、卡片 24 px、导航 24 px、普通控件 14 px、首页行动按钮 18 px；以同级关系保持一致，图标和数据本身不变形。

导航、浮动地图控件、抽屉和局部表单使用半透明浅色底、细高光边、内阴影与柔和外阴影。背景柔化使用 CSS `backdrop-filter`，不模糊文字、地图画布、数据图表或正文。首页主按钮保留绿色层级，次按钮使用深色透明玻璃，文字保持白色。整体为 Apple 风格的 CSS 毛玻璃近似，未实现光学边缘折射，也不照搬视频材质参数。

默认背景模糊 22 px，首页行动按钮 16 px；不支持背景模糊时使用清楚的浅色实体底。减少透明度或增强对比度偏好使用实体底；既有减少动态效果与原位页面切换继续生效。避免嵌套大面积模糊和动态 blur 动画。首页移除“向下了解平台”的提示及其空占位，不增加替代说明。

## 动效

统一规则位于 `public/assets/design-system/motion.css`；页面衔接、滚动揭示与轻量响应位于 `src/design-system/motion.js`。页面、弹层与滚动分别选择动效，不把局部回弹应用到整个工作区。

| 用途 | 当前实现 |
| --- | --- |
| 页面切换 | 主导航切换时内容区原位 150 ms 渐显；共享导航保持实时渲染，无整页位移或缩放 |
| 局部弹层 | 420 ms；围绕自身中心轻微缩放过冲后归位，无向上滑入 |
| 抽屉展开 | 560 ms，`cubic-bezier(.2,.9,.24,1.18)`，一次轻微过冲 |
| 抽屉退出 | 380 ms，`cubic-bezier(.4,0,.8,.2)` |
| 滚动进入 | 420 ms；进入可见范围时轻微缩放与渐显一次，首页主标题不重复播放入场 |
| 滚动响应 | 保留原生滚动；首页卡片追随不超过 8 px 的目标偏移，欠阻尼响应自然收稳 |
| 按下反馈 | 控件短暂缩到 97%，松开后回正 |

贝塞尔过冲和物理弹簧分别命名，不混称。导航、地图、数据读数不随页面卡片漂移。动效结束后不保留额外 transform 层；动画帧、监听和观察器在停止、隐藏或卸载时清理。`prefers-reduced-motion` 直接展示静态终态。

主导航与历史前进后退直接提交路由，在 Vue `nextTick` 后仅对内容区做 150 ms 的透明度过渡；不做整页截图，避免截图期间冻结导航滑动。内部步骤和面板仍使用浏览器 View Transition，等待 `nextTick` 完成目标布局后捕获内容。快速导航跳过旧动画，只提交最后目标。不支持 API 或启用减少动态效果时直接更新。实现依据见 [Chrome 官方文档](https://developer.chrome.com/docs/web-platform/view-transitions/same-document)；跳过视觉过程仍会调用更新回调，所以不能以跳过动画替代取消过期导航。

健康研究内部的录入步骤、研究讨论栏和 AI 助手的会话/资料面板同样复用该入口，保持原位衔接。浏览器历史由 App 在过渡回调中发出 `soilmate:history-commit`，录入组件在该时点恢复步骤，避免在旧画面截图之前直接换页。大型研究侧栏不再叠加另一套缩放入场。

顶栏选中态使用一块共享底板，以独立 CSS transform 过渡在 220 ms 内自然减速到目标，宽度在 180 ms 内适配。View Transition 仅捕获内容区，导航与文字留在实时 DOM；快速点击从底板当前可见位置继续移动，不退回上次目标。导航选中与未选中使用相同字重，避免文字宽度改变造成位置晃动。选中项文字保持深色，导航入口与位置继续统一。

## 文字与验收

标题负责定位，控件名称负责说明操作。删除重复中英标签、常驻操作步骤和填空白的说明；保留单位、来源、质量状态与影响结果解释的条件。补充方法用详情展开。

AI 助手保留一处当前对话标题、问题示例和提问框；本机草稿说明折叠，研究资料按需打开。独立问答/研究关联、存储失败、回答依据和不确定性仍保留。研究页面移除重复的返回入口，草稿与服务范围放入说明，存储失败时展开显示。

以桌面网页为主要验收对象。核对共享导航、页面边线、字体真实加载、动画的过冲与归位、原生滚动、反复打开和减少动态效果。构建通过与用户视觉认可分别记录。

动效原则参考本地 Wiki 的动效与艺术规范；未使用其插画、图标、水景或其他素材。

## 地图底图

地图默认使用高德官方标准/影像服务，天地图保留为另一配置来源。保留底图原色和服务自身的 Logo、来源/审图标识，土壤专题颜色不受视觉滤镜影响。地图失败或缺少所选来源的 Key 时明确显示状态，不自动退回其他地图。高德显示使用 GCJ-02，数据与点选接口保持 WGS84；专题瓦片也经过显示重投影，不能只转换标记。具体接入、坐标约定与检查范围见 [地图配置](MAP_SETUP.md)。

可复用经验已整理为本地 `$datiao-wiki` 技能。其核心约定是位置稳定的页面衔接、局部适度回弹、统一导航和字体、按信息用途精简文字；具体时长留在本文件与源码中。

## 悬停切换反馈

顶部导航和分段切换使用 `useHoverSelection.js` 的同一套规则：鼠标悬停或键盘聚焦时移动底板，离开后保留最后位置；只有点击才改变路由、筛选或数据选项，`aria-current` / `aria-selected` / `aria-pressed` 始终表示实际选择。实际选项被点击或外部状态更新后，底板同步到新选择。触屏忽略悬停事件，保留点击行为；禁用项不能吸引底板。

`HoverSwitch.vue` 将这一行为复用于地图底图与分辨率、图层和结果分类、健康研究阶段、工具分类、数据目录筛选、数据库切换与表列表、研究面板和分析中心页签。组件支持横向、纵向和换行布局，尺寸变化后重新对齐；动画停下后没有运行中的 RAF 或定时器。减少动态效果时直接显示目标位置。
