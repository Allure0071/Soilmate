# Shared interface icons

Selected from the Ant Design outline family, listed on Alibaba iconfont:
https://www.iconfont.cn/collections/detail?cid=9402

The SVG paths are bundled from the official `@ant-design/icons-svg` 4.6.0
package, preserving each original viewBox and path attributes. No icon font,
remote script or runtime dependency is loaded.

Upstream: https://github.com/ant-design/ant-design-icons
Package: https://www.npmjs.com/package/@ant-design/icons-svg/v/4.6.0
License: MIT. The original license is retained at
`frontend/public/licenses/ant-design-icons.txt`.

WorkspaceIcon renders the single-color outline assets with currentColor.
ToolIcon retains the same family's existing TwoTone directory illustrations.
